\begin{abstract}
This paper presents an architecture where a lightweight outer learning layer uses a frozen large language model (LLM) as an environment for autonomous knowledge acquisition. The outer layer observes the LLM's outputs, extracts concepts and features, builds a knowledge graph, and generates questions driven by the graph's own structural gaps. Crucially, the outer layer forms its own abstractions (concept names derived from recurring feature patterns) and then queries the LLM about these self-generated abstractions, creating a cycle where learned structure drives new inquiry. A feedback loop tracks which question strategies produce the most learning and adapts accordingly. In a four-way ablation study over 200 steps, results show that (1) the feedback-driven system produces \textbf{4.9$\times$ denser knowledge graphs} than structure-driven questioning without feedback, (2) every question strategy improves by 34--97\% when feedback is enabled, and (3) structure alone performs worse than random exploration, suggesting that adaptive strategy selection is essential for productive autonomous learning. An extended 2000-step run demonstrates that information gain accelerates rather than plateaus as the knowledge graph densifies. All code and data are publicly available.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Consider a language model trained exclusively on pre-1930 English text. When asked ``What is a microprocessor?'' it responds confidently: ``A microprocessor is a small and inexpensive laboratory appliance for performing delicate microchemical experiments.'' The word does not exist in its world, so it constructs a plausible but entirely fabricated definition by pattern-matching ``micro-'' and ``processor'' to laboratory equipment.

Yet this same model, when asked ``What are electronic gates?'' accurately describes vacuum tubes: ``Electronic gates are the valves which are interposed in an electrical circuit to control the passage of an electric current through the circuit.'' It knows vacuum tubes, their internal structure (filament, plate, grid), and their applications (radiotelegraphy, telephony). When asked ``Can these electronic gates be used for mathematical logical operations?'' it answers \emph{yes}. The model has all the prerequisite knowledge for the electronic computer. It simply never connected the pieces.

What an external questioner did manually (probe, detect incoherence, rephrase, connect) is precisely what an autonomous outer layer should do. These exchanges, conducted with Talkie-1930-13B-IT, are reproduced in full in Appendix~\ref{app:talkie}, where three distinct failure modes (confabulation, domain substitution, and sense drift) are identified. This paper proposes treating the LLM not as a knowledge base to be queried, but as an \emph{environment} to be explored. An outer learning layer, a lightweight neural network with its own state, memory, and learning objectives, interacts with the frozen LLM the way a curious agent interacts with a world. The outer layer observes, abstracts, questions, and integrates. The LLM simply responds.

This framing is inspired by developmental psychology: a child does not passively receive knowledge but actively probes its environment, notices gaps in understanding, and generates questions that fill those gaps \cite{gopnik1999,piaget1952}. The system is not claimed to be a child or to learn the way a child learns. The metaphor is useful for motivation but should not be mistaken for a claim about cognitive capabilities. What the system does is build co-occurrence statistics, test whether new text matches existing patterns, and learn which exploration strategies produce the most information gain.

The central empirical question is: \textbf{does it matter how questions are generated?} A controlled ablation study comparing four strategies shows that it matters enormously. The feedback-driven system (which learns from past questioning success) produces knowledge graphs that are nearly five times denser than any alternative.

\subsection{Contributions}

\begin{enumerate}[leftmargin=*]
\item \textbf{Architecture:} An outer learning layer that uses a frozen LLM as an environment, separating the ``what to ask'' decision from the ``how to articulate'' capability. The outer layer forms its own abstractions and queries the LLM about them.
\item \textbf{Iterative methodology:} Six development versions document the progression from keyword accumulation through mode collapse, self-regulation, passive perception, neurogenesis, and feedback-driven learning, with each version motivated by specific failures of the previous one.
\item \textbf{Ablation study:} Four question generation strategies (random, template, structure-driven, feedback-driven) are compared, showing that feedback produces 4.9$\times$ more connections per concept.
\item \textbf{Emergent meta-learning:} A strategy reversal phenomenon is documented where the worst-performing strategy at step 20 becomes the best by step 200, driven entirely by the feedback loop adapting to the growing knowledge graph.
\item \textbf{Open implementation:} All code, data, and figures are publicly available under MIT licence.
\end{enumerate}

\section{Architecture}
\label{sec:arch}

The system has two components: an \textbf{Environment} (frozen LLM) and an \textbf{Outer Layer} (learning agent). These interact through a cycle of observation, abstraction, questioning, and integration. Table~\ref{tab:analogy} maps the architecture to a developmental analogy that motivates the design.

\subsection{Environment}

The environment is a frozen LLM (Llama 3 8B Instruct, 4-bit quantised) that serves two functions:

\begin{enumerate}[leftmargin=*]
\item \textbf{World:} When prompted, it generates text about any topic. The outer layer treats this text as ``experience'' to learn from.
\item \textbf{Articulator:} When the outer layer identifies a structural question (e.g., ``concept A has feature X but concept B does not''), the LLM formulates a natural-language question from this structural seed.
\end{enumerate}

Critically, the LLM's weights are never modified. It is the world, not the learner.

\subsection{Outer Layer}

The outer layer maintains three components:

\paragraph{ConceptNet.} A small neural network ($\sim$52K parameters) that maps sentence embeddings to concept-level representations. Concepts are discovered through a novelty threshold: when an observation's embedding is sufficiently dissimilar to all known concepts, a new concept is created (``neurogenesis''). Each concept accumulates features, activation counts, and connection edges.

\paragraph{Abstract Formation.} The outer layer does not merely store raw features. It forms \emph{abstractions}: concept names derived from the most frequently recurring features across experiences. These abstractions are then used as query terms when generating new questions. The system asks the LLM about concepts that exist only in the outer layer's own vocabulary, not in the original prompts. For example, from accumulated features about interconnection and possession, the system generated concepts named \texttt{things\_like\_further} and \texttt{world\_involves\_things}. It then asked the LLM about these self-generated entities, producing the highest information gain scores in the entire run. This creates a feedback cycle: accumulated knowledge produces abstractions, abstractions drive new questions, and answers refine the abstractions. The LLM is asked about entities it did not name, entities the outer layer invented from patterns in the LLM's own outputs.

\paragraph{Knowledge Graph.} An undirected graph where nodes are concepts and edges represent shared features discovered through experience. Edge weights encode the number of shared features. The graph's structure drives question generation.

\paragraph{Strategy Selector.} Five question strategies that leverage the knowledge graph's structure:

\begin{itemize}[leftmargin=*]
\item \textbf{Feature gap:} Concept A has feature X, concept B does not. Ask whether B can have X.
\item \textbf{Shared feature:} Feature X appears in both A and B. Ask why.
\item \textbf{Connection:} A and B are connected via shared feature X. Explore the connection.
\item \textbf{Unvisited:} Concept A has low activation count. Ask about it.
\item \textbf{Combine:} Merge features from A and B into a novel question.
\end{itemize}

In feedback mode, each strategy carries a weight that is updated based on a rolling average of information gain from recent uses. Strategies that produce more learning are selected more often.

\subsection{Learning Loop}

At each step, the system operates in one of two modes:

\begin{enumerate}[leftmargin=*]
\item \textbf{Passive observation:} The LLM generates text from an open-ended prompt. The outer layer extracts features, activates matching concepts, updates connection weights, and can trigger neurogenesis, all without asking a question. The system \emph{learns} during passive steps: concept representations and the knowledge graph are modified by every observation. This is not idle waiting; it is unguided perception.
\item \textbf{Active questioning:} The outer layer selects a strategy, generates a structural question seed from the knowledge graph, sends it to the LLM for articulation, then sends the articulated question to the LLM for an answer. The answer is processed as new experience.
\end{enumerate}

The transition between passive and active modes is driven by a surprise signal: the outer layer tracks running statistics of embedding novelty and switches to active questioning when surprise falls below a threshold (the environment has become ``predictable''). This creates a natural rhythm of exploration and exploitation. In the extended run (Section~\ref{sec:extended}), 65.8\% of all steps are passive, making unguided perception the dominant mode of learning.

\section{Methodology: Iterative Development}
\label{sec:method}

The architecture described in Section~\ref{sec:arch} was not designed from first principles. It was discovered through six development iterations, each motivated by specific failures of the previous version. This section documents the progression because the failures are informative: they reveal what is necessary for autonomous knowledge acquisition and what is not sufficient.

\subsection{v0: Keyword Accumulation}

The initial version used raw keyword extraction as its learning mechanism. After 200 steps, only 2 of 6 seed concepts had been activated and zero connections were formed. Keywords are too shallow to support concept-level learning; they capture surface tokens without building relational structure.

\subsection{v1--v2: Mode Collapse and Self-Regulation}

Replacing keyword extraction with a GRU-based neural representation (v1) immediately produced richer activations, but introduced a critical failure: \emph{mode collapse}. Within 50 steps, the concept \texttt{animal} consumed 87\% of all activations. The GRU learned to route everything to a single attractor because the gradient signal rewarded activation of any concept, not diverse activation.

Four self-regulation mechanisms were introduced in v2 to counteract collapse:

\begin{itemize}[leftmargin=*]
\item \textbf{Habituation:} If the same concept activates 3 times consecutively, suppress it. Functionally analogous to boredom.
\item \textbf{Norm clamping:} Prevent any concept vector from growing more than 50\% larger than others. Analogous to discomfort from excess.
\item \textbf{Entropy regularisation:} Add a loss term that penalises low-entropy activation distributions. Analogous to curiosity.
\item \textbf{Exploration bonus:} Boost the activation of under-visited concepts. Analogous to playfulness.
\end{itemize}

With these mechanisms, all 6 seed concepts activated within 50 steps. The self-regulation is not programmed behaviour; it emerges from the interaction of four competing pressures. These mechanisms function analogously to the role of affect in biological learning: boredom prevents fixation, discomfort prevents runaway growth, curiosity promotes exploration, and playfulness rewards novelty.

\subsection{v3--v4: Structure-Driven Questions and Passive Perception}

v3 introduced structure-driven questioning, where the knowledge graph's topology (feature gaps, shared features, connections) determines what to ask. This produced 40 connections, a qualitative leap from v0's zero. However, 2 of 6 concepts (\texttt{bird} and \texttt{tree}) were never activated across 150+ steps. Active questioning alone constrains the exploration scope to what the system already knows.

v4 added passive perception: between active questioning steps, the system passively observes LLM outputs and integrates features without generating questions. The effect was immediate. \texttt{bird}, which never activated in 150 steps of active-only operation, became one of the most active concepts within 50 steps of passive observation. Passive perception broadens the learning aperture by allowing the system to encounter concepts it would never have thought to ask about.

The deeper significance of passive perception is that the system's exposure to concepts is no longer determined solely by its own questions. The world speaks to the system through a continuous text stream, and the system absorbs, extracts, and integrates from that stream without choosing what to attend to. This is a primitive form of subjectivity: the system has experiences it did not select. Active questioning provides agency; passive observation provides the uncontrolled encounters that prevent the system from collapsing into a narrow self-reinforcing loop.

\subsection{v5: Neurogenesis}

v5 introduced concept growth (``neurogenesis''), allowing the system to discover new concepts beyond the initial seeds. The first approach (v5.0) used embedding-space novelty: create a new concept when an observation's embedding is far from all existing concept embeddings. This produced \emph{zero growth events} in 50 steps. MiniLM-L6-v2 embeddings are sufficiently coarse that 6 seed concepts cover the entire output space of the LLM.

The successful approach (v5.1) used feature-frequency growth: any word appearing 4+ times across 3+ distinct concepts becomes a candidate for promotion to a full concept. This grew the graph from 6 to 20 concepts. The key insight is that neurogenesis should be driven by accumulated structural evidence, not raw embedding distance.

\subsection{v6: Feedback Loop}

v6 added strategy-level feedback. Each of the five questioning strategies maintains a rolling average of information gain from its recent uses. Strategies that produce more learning are selected proportionally more often. This is the version evaluated in the ablation study (Section~\ref{sec:results}).

\FloatBarrier

\begin{itemize}[leftmargin=*]
\item \textbf{Random:} Generic prompts with no concept awareness (``Tell me about something interesting'', ``What is knowledge?'').
\item \textbf{Template:} Fixed templates that reference concept names (``Tell me about \{concept\}'', ``Can \{A\} be like \{B\}?'') but do not use the knowledge graph's structure.
\item \textbf{Structure:} Questions are generated from structural analysis of the knowledge graph (feature gaps, shared features, connections), with equal strategy weights (no learning).
\item \textbf{Feedback:} Full system. Structure-driven questions with strategy weights updated based on rolling average information gain.
\end{itemize}

\subsection{Protocol}

All runs use identical conditions:

\begin{itemize}[leftmargin=*]
\item \textbf{Steps:} 200 per run
\item \textbf{Random seed:} 42
\item \textbf{Concept ceiling:} 20 (hard cap on neurogenesis)
\item \textbf{Model:} Llama 3 8B Instruct 4-bit (MLX)
\item \textbf{Hardware:} Apple M3 (local)
\item \textbf{Initial state:} 6 seed concepts (bird, fire, water, metal, animal, tree) with 5 features each
\item \textbf{Output:} Separate state directories per mode
\end{itemize}

\subsection{Metrics}

\begin{itemize}[leftmargin=*]
\item \textbf{Connection density} (connections per concept): Primary metric. Measures how interconnected the learned knowledge graph is.
\item \textbf{Information gain (IG):} Per-step metric combining concept activation, feature extraction, and connection discovery.
\item \textbf{Concept count:} Total concepts discovered (via neurogenesis threshold).
\item \textbf{Active/passive ratio:} How many steps involved active questioning vs. passive observation.
\end{itemize}

This is not simply a matter of selecting better strategies more often. The feedback loop creates a compounding advantage: better questions produce denser knowledge graphs, which give \emph{all} strategies richer material to work with. The improvement is systemic, not selective.

\subsection{Emergent Meta-Learning: Strategy Reversal}

The most striking result is a strategy reversal observed in the feedback run. At step 20, the \texttt{connection} strategy had the lowest average IG (2.4) of all strategies. By step 200, it had the highest (16.57). This reversal was not programmed; it emerged from the interaction between the feedback loop and the growing knowledge graph.

The explanation: \texttt{connection} questions require existing edges in the knowledge graph to be productive. At step 20, the graph has few connections, so connection-based questions produce little learning. But as the graph densifies (partly through other strategies), connection questions become increasingly productive because they leverage the accumulated structure. The system's questioning strategy adapted to the density of its own knowledge without external instruction.

\subsection{Why Structure Performs Worse Than Random}

Counterintuitively, structure-driven questioning without feedback (62 connections) performs worse than random exploration (119 connections). Without feedback, the structure mode defaults to a fixed distribution over strategies, with \texttt{feature\_gap} dominating (14 uses vs.\ 4 for \texttt{connection}). Feature-gap questions ask about what the graph \emph{lacks}, producing isolated facts rather than bridging connections.

Random exploration, by contrast, occasionally stumbles into productive territory by accident. The absence of strategy imposes no constraint on exploration scope. This finding suggests that \textbf{informed exploration without adaptation is worse than uninformed exploration}, a result with implications for curriculum learning and active learning more broadly.

\subsection{Feedback Mode Asks More Questions}

Feedback mode produced 82 active steps compared to 48--58 for other modes. Higher-IG questions also produce more surprise in the embedding space, which triggers more active questioning cycles. Better questions do not just produce more learning per question; they also trigger \emph{more} questions. This positive feedback loop (better questions $\to$ more learning $\to$ more surprise $\to$ more questions) compounds the advantage.

The passive stream provides the majority of the system's exposure: 65.8\% of all learning steps are unguided encounters with the LLM's text, where the outer layer absorbs features and activates concepts without choosing what to attend to.

\paragraph{Accelerating returns.} Information gain does not plateau; it accelerates. Average IG per 400-step window: 15.1 (steps 0--400), 38.3 (400--800), 61.7 (800--1200), 79.8 (1200--1600), 100.3 (1600--2000). Figure~\ref{fig:ig_accel} visualises this compounding effect. \begin{figure}[!htbp]
\centering
\includegraphics[width=\columnwidth]{figures/fig4_ig_acceleration.pdf}

\paragraph{Question repetition.} Without question memory, the system generated 26 questions containing ``What is water?'' across 685 active steps: 14 exact duplicates and 12 LLM-articulated variants of the same structural seed. ``What is bird?'' was repeated 8 times. Exact duplicates waste approximately 3\% of active steps; including near-duplicates, the figure is closer to 5\%. A self-referential extension that tracks question history is the primary target for the next version.

\paragraph{Concept quality.} Of the 200 concepts, 18 (9\%) are function words or morphological fragments (``ing'', ``don'', ``eted'') that passed the frequency-based growth filter. Semantic validation during neurogenesis would improve concept purity without requiring supervised filtering.

\section{Discussion}
\label{sec:discussion}

\subsection{The LLM as Environment}

The architectural choice to treat the LLM as an environment rather than a subject has several advantages:

\begin{enumerate}[leftmargin=*]
\item \textbf{Separation of concerns:} The outer layer decides \emph{what} to ask; the LLM decides \emph{how} to answer. Neither modifies the other's weights.
\item \textbf{Composability:} The same outer layer could interact with different LLMs, knowledge bases, or even human interlocutors.
\item \textbf{Interpretability:} The knowledge graph is an explicit, inspectable representation of what the system has learned.
\item \textbf{Bounded knowledge environments:} LLMs with limited training data (e.g., pre-1930 corpora) provide a natural ``knowledge wall'' for studying how an outer layer handles gaps and incoherence.
\end{enumerate}

\subsection{Neurogenesis: A Negative Result}

The failure of embedding-space novelty for neurogenesis (Section~\ref{sec:method}, v5) is worth highlighting. The intuition that ``semantically distant observations should produce new concepts'' is natural but incorrect when the embedding model's representation is coarse relative to the concept space. MiniLM-L6-v2 maps all LLM outputs into a region that the 6 seed concepts already cover. Feature-frequency growth succeeds because it operates at a finer granularity: it detects recurring \emph{patterns within} the embedding space rather than measuring distance \emph{across} it. This has implications for any system using embeddings for novelty detection.

\subsection{Limitations}

\begin{itemize}[leftmargin=*]
\item \textbf{No question memory:} The most significant architectural gap. At 2000 steps, the system repeated ``What is water?'' 14 times. A self-referential system should know what it has already asked and whether re-asking is justified by changes in its own knowledge state.
\item \textbf{Concept quality at scale:} 9\% of concepts at scale are function words. Feature-frequency growth needs semantic filtering, not just frequency thresholds.
\item \textbf{Ceiling effects:} Both the 200-step (cap=20) and 2000-step (cap=200) runs hit the concept ceiling. True concept discovery dynamics remain masked.
\item \textbf{Single seed:} All runs use seed 42. Results have not yet been verified as robust across seeds.
\item \textbf{Single model:} Llama 3 8B only. Different base models may produce different dynamics.
\item \textbf{No verification:} The system does not check whether the LLM's answers are correct. It trusts the environment. Incoherence detection is a necessary extension (see Appendix~\ref{app:talkie} for evidence of the failure modes this would address).
\end{itemize}

\subsection{The Recursive Insight}

There is a recursive quality to this research that bears noting. The system, which reflects on its accumulated knowledge graph to generate questions that produce new knowledge, mirrors the research process itself. The project began with a plan to study LoRA adapters, pivoted to surprise-driven exploration, then to concept learning, and finally to feedback-driven question generation. Each pivot was driven by reflecting on accumulated results and identifying the most productive next question. The outer layer's strategy reversal (from exploration to exploitation as structure accumulates) recapitulates the researcher's own trajectory.

This is not a claim about consciousness or understanding. It is an observation that the computational pattern, \emph{growing knowledge + structural reflection = emergent direction for new inquiry}, appears at multiple scales of the system.


%% ============================================================
\section{Related Work}
\label{sec:related}

\textbf{Curiosity-driven exploration} in reinforcement learning uses intrinsic motivation signals (prediction error, information gain, novelty) to guide agent behaviour \cite{pathak2017,burda2019,schmidhuber1991}. The present approach differs in using a knowledge graph's structure rather than raw prediction error to define ``interesting'' directions. The surprise-based active/passive switching is a variant of Schmidhuber's compression progress framework \cite{schmidhuber1991}.

\textbf{Developmental learning.} Piaget's accommodation/assimilation framework \cite{piaget1952} directly parallels the concept learning mechanism: new observations either assimilate into existing concepts (activation) or trigger accommodation (neurogenesis). Oudeyer and Kaplan's intrinsic motivation framework \cite{oudeyer2007} formalises similar intuitions in computational terms.

\textbf{Active learning} selects training examples that maximise model improvement \cite{settles2009}. The system presented here extends this by generating queries rather than selecting from a pool.

\textbf{Few-shot concept learning.} The ConceptNet's concept representations, where feature vectors serve as prototypes, parallel prototypical networks \cite{snell2017}. Lake et al.\ \cite{lake2017} argue for machines that build causal models rather than matching patterns; the outer layer's structural questioning embodies this distinction.

\textbf{Knowledge graph construction} from text typically uses supervised information extraction \cite{ji2022}. The present system builds knowledge graphs through interaction rather than extraction, without labelled data or pre-defined relation types.

\textbf{LLM-based agents} that use language models as reasoning engines for task completion \cite{yao2023} share the framing of the LLM as a tool. However, these agents pursue externally defined goals; the present system pursues internally generated curiosity signals.


%% ============================================================
\section{Future Work}
\label{sec:future}

\paragraph{Self-referential question memory.} The most immediate extension is a two-level novelty gate: (1) embedding deduplication to suppress near-duplicate questions, and (2) a structural novelty gate that checks whether the concepts involved in a candidate question have gained new features since the last time they were queried. This is the bridge from concept learning to self-modelling: the system reasons about its own past behaviour to constrain future behaviour.

\paragraph{Incoherence detection.} The current system trusts all LLM outputs. A production-grade system needs multi-signal verification: coherence checking against the knowledge graph, surprise detection, abstract rephrasing, and multi-probe convergence. Appendix~\ref{app:talkie} documents three distinct failure modes (confabulation, domain substitution, sense drift) that the outer layer must learn to detect.

\paragraph{Self-synthesis.} When the base model cannot answer a question satisfactorily, the outer layer could attempt to synthesise an answer from its own knowledge graph, bridging concepts that the LLM never connected.


%% ============================================================
\section{Conclusion}
\label{sec:conclusion}

This paper presented a system where a lightweight outer layer autonomously builds knowledge by using a frozen LLM as an environment. The outer layer forms its own abstractions from accumulated experience and queries the LLM about these self-generated concepts, creating a cycle of abstraction and inquiry. A four-way ablation study demonstrates that how questions are generated matters enormously: feedback-driven strategy selection produces 4.9$\times$ denser knowledge graphs than structure-driven questioning without adaptation, and every individual strategy improves by 34--97\% when feedback is enabled.

The most striking finding is that informed exploration without adaptation performs \emph{worse} than random exploration. Structure alone constrains the exploration space too narrowly. Feedback is what transforms structure from a liability into an advantage.

The system exhibits emergent meta-learning: the worst strategy at step 20 becomes the best by step 200, driven entirely by the interaction between the feedback loop and the growing knowledge graph. An extended 2000-step run demonstrates that information gain accelerates rather than plateaus, suggesting that the feedback loop compounds as knowledge density increases.

The methodology section documents that the final architecture was not designed top-down but discovered through six iterations of failure and correction. Each failure (mode collapse, limited activation, neurogenesis failure) motivated a specific architectural solution. The failures are as informative as the successes.

\section{Talkie-1930 Interaction Evidence}
\label{app:talkie}

The following exchanges were conducted manually with Talkie-1930-13B-IT, a language model trained on pre-1931 English text. They demonstrate three failure modes that an autonomous outer layer must learn to detect and handle. These exchanges motivated the architecture presented in this paper.

\paragraph{Exchange 1: Confabulation.}
\emph{``What is a microprocessor?''} The model responds: ``A microprocessor is a small and inexpensive laboratory appliance for performing delicate microchemical experiments. It consists essentially of a small water bath, heated by a spirit lamp.'' The word does not exist in the model's training data. It constructs a plausible but fabricated definition by pattern-matching ``micro-'' + ``processor'' to laboratory equipment. \textbf{Detection signal:} zero feature coherence with existing knowledge.

\paragraph{Exchange 2: Domain substitution.}
\emph{``Can I connect logic gates AND OR XOR and put them in high density for complex calculations?''} The model responds: ``I can connect two pieces of railway so that they form a continuous line, and I can create a high density of traffic upon them.'' The model recognised the \emph{pattern} of the question (connect X densely to create Y) and mapped it to its strongest association: railway engineering. \textbf{Detection signal:} topic mismatch between question domain and answer domain.

\paragraph{Exchange 3: Sense drift.}
\emph{``What are logic gates?''} The model responds: ``Logic gates are certain forms of words, set up as marks or limits, beyond which a particular kind of argument must not pass.'' In the pre-1930 world, ``logic gates'' means rules of Aristotelian syllogistic reasoning. The words are correct; the meaning has drifted. \textbf{Detection signal:} correct vocabulary but unexpected features.

\paragraph{Exchange 4: Correct retrieval.}
\emph{``What are electronic gates?''} The model accurately describes vacuum tubes: ``Electronic gates are the valves which are interposed in an electrical circuit to control the passage of an electric current.'' It describes the internal structure (filament, plate, grid) and applications (radiotelegraphy, telephony).

\paragraph{Exchange 5: Cross-domain connection.}
\emph{``Can these electronic gates be used for mathematical logical operations?''} The model answers \emph{yes} and describes the Brunsvig Calculator. The model has all the prerequisite knowledge for the electronic computer but never connected the pieces on its own. What the questioner did manually (probe, detect incoherence, rephrase, connect) is precisely what the outer layer should learn to do autonomously.
